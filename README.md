# 📦 Samsung Supply Chain & Logistics Analytics Dashboard

An interactive Power BI dashboard project designed to analyze and monitor Supply Chain, Inventory, Shipment, Supplier, and Customer performance using business intelligence techniques.

---

# 📌 Project Overview

This project focuses on transforming raw supply chain and logistics data into meaningful business insights using Power BI.  

The dashboard helps analyze:

- Supplier performance
- Inventory management
- Shipment tracking
- Customer analytics
- Revenue & profit insights
- Logistics operations

The main goal of this project is to support better business decision-making through interactive dashboards and visual analytics.

---

✅ Interactive Power BI Dashboards

## 🏠 Home Dashboard
- Attractive landing page
- Easy navigation between dashboards
- Professional dashboard design

## 📈 Overview Dashboard
Provides overall business performance insights including:

- Total Revenue
- Total Profit
- Profit Margin %
- Order Quantity
- Shipment Quantity
- Delivered Quantity
- Supplier Lead Time
- Delay Shipment Analysis

---

## 🚚 Supplier Dashboard
Analyzes supplier-related performance such as:

- Unit Cost Analysis
- Order Quantity Tracking
- Supplier Lead Time
- Supplier Quality Score
- Supplier Country Analysis
- Average Quantity Metrics

---

## 📦 Inventory Dashboard
Focuses on inventory management and stock analysis including:

- Inventory Value Tracking
- Safety Stock Monitoring
- Defective Unit Analysis
- Reorder Point Analysis
- Turnover Rate
- Days of Inventory

---

## 🚛 Shipment Dashboard
Tracks shipment and logistics performance:

- Shipment Cost Analysis
- Delivered Shipment Tracking
- Delay Shipment Analysis
- Shipment Status Distribution
- Monthly Shipment Trends

---

## 👥 Customer Dashboard
Provides customer and sales analytics:

- Revenue & Profit Analysis
- Customer Sales Insights
- Product Discount Analysis
- Channel-wise Revenue
- Monthly Revenue Growth

# ▶️ How to Use

1. Download the `.pbix` file from this repository.
2. Open the file using Power BI Desktop.
3. Explore different dashboard pages.
4. Use filters and slicers for interactive analysis.
5. Analyze KPIs and business insights.
